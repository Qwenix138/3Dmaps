# Blender

1. Импортируйте `*.glb`: **File → Import → glTF 2.0**.
2. Серый объект — это Solid-режим. Нажмите `Z` и выберите **Material Preview**.
3. Подписи и схема запечены в текстуру; здания, дороги и железные дороги — отдельная геометрия.
4. Если объектов нет, проверьте `counts.buildings` и `counts.roads` в `meta.json` и импортируйте новый GLB.
5. Если модель не видна: `Numpad .` (Frame Selected), затем увеличьте **Clip End** в настройках вида.

OBJ: `X` — восток, `Y` — север, `Z` — вверх. GLB: `X` — восток, `Y` — вверх, `Z` — юг.
