# Android APK

[Русский](README.md) · [English](README.en.md)

[`3Dmaps-0.2.10.apk`](https://github.com/Qwenix138/3Dmaps/releases/download/v0.2.10/3Dmaps-0.2.10.apk) — автономное Android-приложение. Внутри APK уже лежит интерфейс и генератор: отдельный сервер, Termux, Python и настройка адреса не нужны.

## Установка

1. Скопируй APK на телефон и разреши установку из неизвестных источников.
2. Установи `3Dmaps-0.2.10.apk`. Версия 0.2.10 обновляет 0.2.9/0.2.8/0.2.7/0.2.6/0.2.5/0.2.4/0.2.3/0.2.2/0.2.1/0.2.0/0.1.0, package тот же — `com.opencode.mapgen`.
3. Открой 3Dmaps, выбери язык RU/EN в шапке, нажми «Рамка» и проведи прямоугольник. Меняй зону за углы и стороны, перемещай за центральную точку или изнутри либо нажми пресет.

Нужен интернет: карта, контуры OSM, высоты Terrarium и спутник EOX загружаются из сети. Сама генерация, расчёт геометрии и сохранение файлов выполняются на телефоне.

## Что нового в 0.2.10

- Исправлена загрузка OSM для плотных городов вроде Нью-Йорка: при лимите OSM API 50 000 узлов используется Overpass, а если он недоступен — плитки OSM API. Ошибки всех источников теперь видны в сообщении.
- Русский и английский интерфейс; выбор языка сохраняется.
- Пресеты качества «Быстро / Баланс / Детально».
- Сводка результата: площадь, треугольники, здания, дороги и предупреждения.
- Улучшенный дизайн панелей и списка файлов.
- Сохранены исправления 0.2.7/0.2.8/0.2.9: правильные расширения `.obj`/`.mtl`, высота рельефа, сглаживание DEM, пресеты и сводка результата.

## Что внутри

- Собственная карта OSM без Leaflet и внешних CDN.
- Поиск места через Nominatim и кнопка «Моё место»; обе используют выбранный размер зоны.
- Выделение прямоугольной зоны с 8 ручками, перемещением изнутри, пресетами 0.5–3 км и точными размерами.
- Шаг рельефа 10–60 м, высота 0.5×–2×, сглаживание DEM, текстура 512/1024/2048 px.
- Быстрое сохранение только GLB или OBJ+MTL; для OBJ дополнительно сохраняются текстуры.
- Рельеф из Terrarium DEM; при сбое тайла используется нейтральная высота.
- Здания, дороги и железные дороги из OSM: OSM API для небольших зон, Overpass для плотных городов и больших зон.
- Спутник Sentinel-2 cloudless через EOX WMS; при ошибке — локальная рельефная текстура.
- OBJ+MTL, GLB, PNG-heightmap, метаданные и текстуры.
- Сохранение в `Download/3Dmaps/<название>/` на Android 10+. На старых версиях при отказе в доступе — в `Android/data/com.opencode.mapgen/files/Download/3Dmaps/`.

Ограничения:

- Максимальная зона — 15 × 15 км (225 км²). Плотные города вроде Нью-Йорка загружаются через Overpass; первый такой запрос может быть заметно дольше.
- Текстура — 512–2048 px. 4096 на телефоне может привести к нехватке памяти.
- Спутник EOX имеет лицензию CC BY-NC-SA 4.0: только некоммерческое использование.
- Google-тайлы и Google 3D не используются.

## Сборка

Требуются JDK 17, Android SDK 35 и Gradle 8.9.

```bash
cd android
ANDROID_HOME=/path/to/android-sdk GRADLE_BIN=/path/to/gradle-8.9/bin/gradle bash build-apk.sh
```

Скрипт собирает в `/tmp/3dmapgen-android-build`, чтобы Gradle не спотыкался о кириллицу в пути проекта, и копирует APK в `../release/3Dmaps-<version>/3Dmaps-<version>.apk`. На этом устройстве используются:

- `ANDROID_HOME=/root/android-sdk`
- `GRADLE_BIN=/root/tools/gradle-8.9/bin/gradle`
- Termux `aapt2` с `LD_LIBRARY_PATH` (подхватывается скриптом)

APK подписан debug-ключом из `~/.android/debug.keystore`; для личной установки этого достаточно. Для публикации нужен отдельный release-ключ.

Исходники приложения:

```text
android/app/src/main/
├── AndroidManifest.xml
├── java/com/opencode/mapgen/MainActivity.java
├── assets/web/index.html
├── assets/web/style.css
├── assets/web/core.js
└── assets/web/app.js
```

Старые APK 0.2.3–0.2.9 удалены. Если остался файл `*.obj.txt`, переименуй его в `*.obj` или сохрани заново: начиная с 0.2.7 OBJ получает правильное расширение.
